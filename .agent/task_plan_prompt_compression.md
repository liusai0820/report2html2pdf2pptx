# Task Plan: Prompt 精简与优先级重构

## Goal
通过"高信息密度压缩词"技术精简 Prompt，确保 AI 能优先遵守最重要的约束（如防止溢出）。

## 问题分析

### 当前问题
1. **溢出问题持续发生**：尽管添加了大量指令，AI 仍然产出溢出的内容
2. **Prompt 过长**：指令太多，AI 无法兼顾所有要求
3. **优先级不清晰**：AI 不知道哪些规则是"必须遵守"vs"建议遵守"

### 根本原因
- Prompt 中信息过载，关键规则被淹没
- 大量举例和描述性文字分散了注意力
- 缺乏清晰的优先级层次

## "高信息密度压缩词"技术

### 原理
用 AI 已经"内化"的概念词替代冗长描述。

### 示例对比

| 冗长描述 | 压缩词 |
|---------|--------|
| "使用顶部结论、支撑论点分层展开的结构" | **金字塔原理** |
| "像麦肯锡咨询报告那样专业、精炼、有洞察" | **麦肯锡风格** |
| "确保内容不超出容器边界，使用 overflow:hidden" | **CSS 盒模型约束** |
| "使用 padding/margin 控制间距，box-sizing:border-box" | **盒模型 border-box** |
| "画布 1280x720，底部80px预留，内容不能溢出" | **安全区约束** |

# Notes: Prompt 结构分析

## 当前 Prompt 规模统计

| Prompt 部分 | 字符数 | 行数 | 问题 |
|-------------|--------|------|------|
| DESIGNER_SYSTEM_PROMPT | ~6,600 | 175 | 规则太多，优先级不清 |
| _build_content_prompt | ~11,700 | 270 | 重复 + 冗长举例 |
| **总计正文页 Prompt** | **~18,300** | ~445 | ⚠️ 过长！ |

## 当前 Prompt 结构问题

### 1. DESIGNER_SYSTEM_PROMPT 内容分析

```
├── 画布约束 (重要!)
├── 核心使命
├── 设计原则
│   ├── 内容精炼
│   ├── 内容优先
│   └── 视觉优先
├── 布局自由
├── 禁止事项 (重要!)
├── 颜色规范
├── ECharts 支持 (太长!)
│   ├── 基础用法
│   ├── 常见问题修复
│   └── 标准模板
└── 输出要求
```

### 2. 关键问题识别

**问题 A：优先级不分层**
- 所有规则看起来同等重要
- AI 不知道"溢出"是红线级错误

**问题 B：重复描述**
- 画布约束在 System Prompt 和 Content Prompt 都有
- ECharts 规范描述了两次

**问题 C：举例过多**
- ECharts 常见问题列了 4 条，每条有原因+修复
- 可以用一个"压缩词"替代

## 压缩方案建议

### 策略 1：建立优先级层次

```
🚨 红线规则（必须遵守，违反=失败）
   - 内容不溢出画布
   - 不使用禁用字体

⚠️ 重要规则（强烈建议）
   - ECharts 配置规范
   - 颜色规范

💡 风格指南（可灵活处理）
   - 设计原则
   - 布局建议
```

### 策略 2：使用压缩词替代冗长描述

| 当前描述 | 压缩词建议 |
|---------|-----------|
| 画布 1280x720，底部 80px 预留... | **PPT安全区模型** |
| 像麦肯锡报告那样... | **麦肯锡风格** |
| 金字塔原理的结构化表达... | **MECE原则** |
| ECharts grid 配置 70/40/40/30... | **ECharts标准边距** |
| 使用 overflow:hidden 防止溢出 | **CSS 盒模型约束** |

### 策略 3：精简 ECharts 部分

**当前**：~2000 字符的 ECharts 说明
**压缩后**：~500 字符

```
## ECharts 规范
- grid: { left:70, bottom:40, containLabel:true }
- 最小尺寸: 300px × 180px
- 数值差距 >10倍：改用表格
- 必须设置 animation:false
```

### 策略 4：突出红线规则

在 Prompt 开头用醒目方式强调：

```
## ⛔ 红线规则（违反=失败）
1. 内容必须在 1280×640 安全区内（底部 80px 禁区）
2. 必须使用 overflow:hidden
3. 不得使用禁用字体
```

## 预期效果

- Prompt 总长度减少 40%+
- 关键规则优先级清晰
- AI 更容易遵守溢出约束

# Task Plan: 优化 ECharts 图表生成质量

## Goal
解决 AI 生成的 ECharts 图表中的溢出、截断、样式丑陋等问题，提升图表可视化质量。

## 问题分析（基于用户截图）

### 问题 1：Y轴数字被截断
- 现象：Y轴显示 ",000"、",500" 而不是 "1,000"、"500"
- 原因：ECharts grid.left 设置太小，左侧空间不够显示完整数字
- 示例：第2、3张截图中的柱状图

### 问题 2：数值差距过大导致小数据不可见
- 现象：2000 vs 50 的对比，50 的柱子几乎看不见
- 原因：使用线性坐标轴时，差距过大的数据会导致小值被压缩
- 解决方案：
  - 使用对数坐标轴（log）
  - 或使用双Y轴
  - 或用百分比/增长率代替绝对值

### 问题 3：图表被极度压缩
- 现象：图表放在狭窄空间内，被压缩变形
- 原因：AI 没有给图表预留足够空间
- 解决方案：设置图表最小高度/宽度

### 问题 4：底部溢出被截断
- 现象：图表底部的标签或坐标被截断
- 原因：ECharts grid.bottom 设置太小
- 解决方案：增加 grid.bottom 值

## 解决方案

### 1. 在 System Prompt 中添加 ECharts 规范

需要在 DESIGNER_SYSTEM_PROMPT 中添加：
- 图表最小尺寸要求
- grid 边距规范
- 数值差距过大时的处理方案
- 避免常见错误

### 2. 具体规范内容

```javascript
// ECharts 配置规范
{
    grid: {
        left: 60,    // 足够显示5位数
        right: 20,
        top: 40,
        bottom: 40,  // 足够显示X轴标签
        containLabel: true  // 重要！自动包含标签
    },
    // 如果数据差距 > 10倍，考虑：
    // 1. 使用 yAxis.type: 'log'
    // 2. 使用多个Y轴
    // 3. 显示增长率而非绝对值
}
```

### 3. 图表容器规范
- 最小高度：200px
- 最小宽度：300px
- 不要在多列布局中放置复杂图表

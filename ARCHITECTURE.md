# 系统架构与分形文档规则

> **⚠️ 一旦本文件被更新，请同步检查根目录 README.md 是否需要更新。**

## 分形文档规则 (Fractal Documentation)

本项目采用**自指、复调**的分形文档结构，灵感来源于《哥德尔、埃舍尔、巴赫》。

### 核心规则

1. **根目录 (`/`)**

   - `README.md`: 项目总览，强调分形规则
   - `ARCHITECTURE.md` (本文件): 架构说明 + 规则详解

2. **每个文件夹**

   - 必须包含 `_FOLDER.md`
   - 内容：3 行以内的架构说明 + 每个文件的 (名字, 地位, 功能)
   - 头部声明：`一旦我所属的文件夹有所变化，请更新我。`

3. **每个代码文件**
   - 头部必须包含 3 行极简注释：
     ```
     @input:  依赖外部的什么
     @output: 对外提供什么
     @pos:    在系统局部的地位
     ```
   - 声明：`一旦我被更新，务必更新：1.我的头部注释 2.所属文件夹的_FOLDER.md`

### 为什么这样做？

- **局部影响整体**：修改一个文件，必须更新其注释和所属文件夹的说明
- **整体影响局部**：阅读任何 `_FOLDER.md`，就能快速理解该目录的全貌
- **AI 友好**：AI 助手可以通过读取少量文件，快速获得项目的完整上下文

## 系统架构

```
                   ┌─────────────────────────────────────────────┐
                   │           Frontend (React/Vite)             │
                   │   components/ → 用户交互界面                  │
                   └─────────────────┬───────────────────────────┘
                                     │ HTTP/SSE
                   ┌─────────────────▼───────────────────────────┐
                   │           Backend (FastAPI)                 │
                   │   server.py → API 网关                       │
                   │   core/     → AI 编排引擎                    │
                   │   v2/       → 下一代设计系统                  │
                   └─────────────────┬───────────────────────────┘
                                     │
          ┌──────────────────────────┼──────────────────────────┐
          │                          │                          │
          ▼                          ▼                          ▼
    ┌───────────────┐      ┌─────────────────┐      ┌─────────────────┐
    │  OpenRouter   │      │   ComfyUI       │      │   Supabase      │
    │  (LLM API)    │      │  (本地图像生成)  │      │  (用户/数据)    │
    └───────────────┘      └─────────────────┘      └─────────────────┘
```

## 目录职责

| 目录        | 职责            | 关键文件                    |
| ----------- | --------------- | --------------------------- |
| `/src`      | Python 后端核心 | `server.py`, `core/`, `v2/` |
| `/frontend` | React 前端      | `App.jsx`, `components/`    |
| `/config`   | 环境配置        | `.env`, `.env.example`      |
| `/scripts`  | 辅助脚本        | PDF 转换、批处理等          |
| `/output`   | 生成产物        | HTML, PDF, PPTX             |

## 外部依赖

| 服务       | 用途             | 配置项                                           |
| ---------- | ---------------- | ------------------------------------------------ |
| OpenRouter | LLM API 网关     | `OPENROUTER_API_KEY`                             |
| Supabase   | 用户认证/数据    | `VITE_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` |
| ComfyUI    | 本地 AI 图像生成 | `COMFYUI_ENABLED`, `COMFYUI_HOST`                |
| Gmail SMTP | 邮件通知         | `SMTP_USER`, `SMTP_PASSWORD`                     |
| Telegram   | 运营告警         | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`         |

## 1. 产品概述

### 1.1 产品定位

**SlideCraft AI** 是一款基于大语言模型的智能演示文稿生成平台，致力于解决用户"从文档到专业PPT"的效率痛点。

**核心价值主张**:
> "上传文档，AI 自动生成专业级演示文稿，10分钟搞定原本需要数小时的PPT制作。"

### 1.2 目标用户画像

| 用户类型 | 典型场景 | 痛点 | 价值点 |
|---------|---------|------|--------|
| 咨询顾问 | 研究报告、战略汇报 | 报告转PPT耗时长 | 快速专业输出 |
| 企业员工 | 年终述职、项目汇报 | 设计能力有限 | 一键美化 |
| 大学生/研究生 | 开题答辩、论文汇报 | 没有设计经验 | 学术风格适配 |
| 政府公务员 | 政策解读、党建汇报 | 格式要求严格 | 场景化模板 |
| 创业者 | 路演BP、产品介绍 | 时间紧迫 | 高效交付 |

## 2. 核心功能清单

### 2.1 文档处理

| 功能 | 描述 | 技术实现 |
|------|------|---------|
| 多格式支持 | PDF, DOCX, Markdown, TXT | pdfplumber, python-docx |
| 智能解析 | 自动提取标题、段落、表格 | DocumentParser |
| 内容截断 | 最多处理 50,000 字符 | 防止 Token 溢出 |

### 2.2 AI 生成引擎

| 功能 | 描述 | 技术实现 |
|------|------|---------|
| 大纲规划 | AI 自动拆分章节和内容要点 | generate_outline() |
| 页面设计 | 每页独立生成 HTML+CSS | generate_page() |
| 并行生成 | 最多 5 页同时生成 | asyncio.Semaphore |
| 自定义指令 | 用户可输入特殊要求 | custom_instructions 参数 |

### 2.3 设计系统

| 场景 | 主色 | 强调色 | 典型应用 |
|------|------|--------|---------|
| 咨询研究 | #003366 (深蓝) | #FFD700 (金色) | 战略报告 |
| 年终述职 | #1A365D (藏青) | #E53E3E (红色) | 工作汇报 |
| 学术答辩 | #1E3A8A (学院蓝) | #F59E0B (琥珀) | 论文答辩 |
| 政府公文 | #C41E3A (中国红) | #FFD700 (金色) | 党建汇报 |
| 创意营销 | #6C5CE7 (紫色) | #FF6B6B (珊瑚) | 品牌推广 |
| 公司介绍 | #0A0A0A (黑色) | #00D4FF (科技蓝) | 项目路演 |

### 2.4 导出能力

| 格式 | 技术方案 | 状态 |
|------|---------|------|
| HTML | 完整单页 + 分页双版本 | ✅ 可用 |
| PDF | Puppeteer 打印 + pdf-lib 合并 | ✅ 可用 |
| PPTX | Adobe PDF Services API | ⚠️ 可选 (需订阅) |

### 2.5 增值功能

| 功能 | 描述 | 价值 |
|------|------|------|
| AI 封面图 | ComfyUI 生成专属封面 | 视觉差异化 |
| Unsplash 图库 | 自动匹配高质量背景 | 专业感提升 |
| ECharts 图表 | 数据自动可视化 | 数据报告利器 |
| 全屏演示 | 内置演示模式 | 即用即演 |

## 3. 技术优势分析

### 3.1 与竞品对比

| 维度 | SlideCraft AI | Gamma | Beautiful.ai | 传统模板工具 |
|------|--------------|-------|--------------|-------------|
| 生成方式 | 文档→PPT 端到端 | 大纲→PPT | 模板+AI建议 | 纯模板 |
| 中文支持 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| 场景适配 | 6大垂直场景 | 通用 | 通用 | 有限 |
| 自定义度 | 主题色+指令 | 中等 | 较高 | 很高 |
| 导出格式 | HTML/PDF/PPTX | PDF/PPTX | PDF/PPTX | PPT |
| 定价 | 灵活配额制 | 订阅制 | 订阅制 | 一次性/订阅 |

### 3.2 核心壁垒

1. **中文场景深耕**: 针对国内用户场景（政务、咨询、学术）深度优化
2. **端到端自动化**: 从文档到成品 PPT，无需人工干预
3. **设计系统沉淀**: 积累的场景化设计规范难以复制
4. **运营数据闭环**: Telegram 通知 + 自动反馈处理 + 配额补偿

### 3.3 待优化领域

| 问题 | 影响 | 优先级 |
|------|------|--------|
| PPTX 导出依赖 Adobe API | 成本高，可能失败 | 高 |
| 图片生成功能开关 | 用户可能困惑 | 中 |
| 移动端适配 | 无法移动端使用 | 中 |
| 多语言支持 | 限制海外市场 | 低 |

## 4. 当前运营状态

### 4.1 用户系统

```
用户注册 → Supabase Auth
    ↓
创建 Profile (配额/套餐/职业)
    ↓
使用配额生成 PPT
    ↓
配额耗尽 → 升级套餐 or 等待补充
```

### 4.2 套餐体系 (现有)

| 套餐类型 | 说明 | 配额 | 有效期 |
|---------|------|------|--------|
| free | 免费试用 | 初始配额 | 无限 |
| deadline | 按需付费 | 按次购买 | 有限 |
| pass | 通行证 | 大额度 | 有限 |
| team | 团队版 | 共享额度 | 有限 |

### 4.3 运营工具

- **Telegram Bot**: 实时通知新用户、上传、反馈
- **每日报告**: 自动聚合并发送运营数据
- **反馈处理**: AI 自动分析 + 配额补偿 + 邮件草稿
- **管理后台**: 用户列表、套餐升级、生成记录

## 5. SWOT 分析

### Strengths (优势)
- ✅ 中文场景深度优化，契合国内用户习惯
- ✅ 端到端自动化，用户体验流畅
- ✅ 多场景适配，覆盖主流使用场景
- ✅ 技术架构现代化，易于迭代

### Weaknesses (劣势)
- ⚠️ PPTX 导出依赖第三方 API，成本与稳定性问题
- ⚠️ 品牌知名度低，需要市场教育
- ⚠️ 团队规模有限，开发资源紧张

### Opportunities (机会)
- 🚀 国内 AI 办公工具市场高速增长
- 🚀 企业数字化转型需求旺盛
- 🚀 大模型能力持续提升，生成质量可期
- 🚀 政务/教育市场对国产工具有政策倾斜

### Threats (威胁)
- ⚡ 大厂入局 (WPS AI, 腾讯文档)
- ⚡ Gamma 等海外工具加速本地化
- ⚡ 用户对 AI 生成质量期望不断提高
- ⚡ API 成本可能上涨

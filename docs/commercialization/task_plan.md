## Key Findings

### 产品概况
- **产品名称**: SlideCraft AI - 智能演示文稿生成平台
- **核心功能**: 从文档(PDF/DOCX/MD/TXT)智能生成专业级 PPT
- **技术栈**: React 18 + FastAPI + LLM (OpenRouter/DeepSeek/Gemini)
- **部署状态**: 已上线运营 (ppt.gwy.life)

### 关键特性
1. V2 AI 编排引擎 - 端到端智能生成
2. 多场景适配（咨询/述职/学术/政务/创意）
3. 自定义主题色 + 设计系统
4. AI/Unsplash 背景图生成
5. ECharts 数据可视化
6. PDF/PPTX 多格式导出
7. 用户系统 + 配额管理 (Supabase)
8. Cloudflare R2 云存储

### 当前商业模式
- 免费试用 + 配额制
- 用户注册后有初始配额
- 支持套餐升级（free/deadline/pass/team）
- Telegram 机器人通知运营

## Decisions Made
- 采用 SaaS 订阅 + 按量付费混合模式
- 定位中高端市场，聚焦 B2B + 高价值 B2C

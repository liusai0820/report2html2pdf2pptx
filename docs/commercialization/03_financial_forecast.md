## 7. 单位经济学

### 7.1 关键指标

| 指标 | 计算方式 | 数值 |
|------|---------|------|
| CAC (获客成本) | 营销费用 / 新付费用户 | ¥104 |
| ARPU (用户均收入) | 总收入 / 活跃用户 | ¥120/月 |
| LTV (用户生命价值) | ARPU × 平均生命周期 | ¥720 |
| LTV/CAC | 投入产出比 | 6.9x |
| 回收期 | CAC / ARPU | 0.87个月 |

### 7.2 单用户经济模型

```
用户生命周期价值分解

      ┌─────────────────────────────────────────────────────────┐
      │                     LTV = ¥720                          │
      ├────────────────────────────┬────────────────────────────┤
      │   首次付费 ¥120           │   续费收入 ¥600 (5次)       │
      │   (获客成本 ¥104)         │   (边际成本接近0)           │
      └────────────────────────────┴────────────────────────────┘
                    │                           │
                    ▼                           ▼
              毛利 ¥16 (13%)              毛利 ¥540 (90%)
```

**洞察**:
- 首单几乎不赚钱，利润来自续费
- LTV/CAC = 6.9x > 3x，商业模式健康
- 应重点关注用户留存和续费

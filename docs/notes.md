## 核心发现

### 1. 目标用户画像
- **用户类型**: 私募股权基金团队（金融投资机构）
- **核心角色**: 投资经理、分析师、基金管理层
- **工作特征**: 
  - 频繁处理PDF/Excel财务数据
  - 定期LP汇报和内部会议
  - 跨项目、跨行业研究需求
  - 多人协作、知识传承需求

### 2. 六大核心需求场景

#### 场景一：投资组合项目定期更新的自动化
- **痛点**: 每季度从被投公司收到财务报表(PDF/Excel)，需手动录入Excel tracker，同步至PPT模板
- **具体需求**:
  - AI识别财务报表结构，自动提取收入、毛利、净利润等核心数据
  - 自动更新Excel模板并计算指标
  - 自动生成图表
  - 初步异常分析与预警
  - 批量处理多家公司数据，自动合并为总汇报文件
- **频率**: 季度性
- **优先级**: ⭐⭐⭐⭐⭐ 极高

#### 场景二：新公司/行业研究
- **特征**: 70%通用结构 + 30%行业差异内容
- **两类子需求**:
  1. **行业入门**: 对不熟悉的行业，需AI快速构建分析框架（上下游结构、市场规模、头部玩家）
  2. **深度研究**: 对已熟悉行业，提出细化问题（如不同子赛道毛利率差异），快速抓取并对比数据
- **期望**: AI自动生成初版研究slides，自动抓取核心数据
- **优先级**: ⭐⭐⭐⭐⭐ 极高

#### 场景三：项目级记忆与上下文跟踪
- **痛点**: 同一项目多人交叉接触，历史信息分散
- **需求**:
  - 建立长期Project Agent
  - 记录历史沟通内容、上传资料、meeting notes
  - 据此给出合理建议（如避免与过往表述冲突）
  - 具备完整memory，实现持续协作与知识留存
- **优先级**: ⭐⭐⭐⭐ 高

#### 场景四：邮件交互中的分析与审批
- **产品形态**: Mail Manus功能（将邮件转发至AI邮箱）
- **场景包括**:
  - 投行teaser自动分析
  - 老板邮件自动转发与处理
  - 自动汇总待审批事项
  - 提供摘要与建议回信
- **优先级**: ⭐⭐⭐⭐ 高

#### 场景五：第三方报告分析与内部流程对接
- **外部报告处理**:
  - 法律、税务、财务尽职调查等冗长PDF
  - AI做白话总结，聚焦当前研究问题
- **内部流程整合**:
  - 股东会决议、风控意见、IC评审
  - 总结不同角色意见并统一提炼
  - 支持企业微信或邮件整合
- **优先级**: ⭐⭐⭐⭐ 高

#### 场景六：数据库调用与量化分析自动化
- **需求**:
  - 调用Capital IQ等专业数据库
  - 获取公司多期数据（收入、存货周转率等）
  - 标准化填入Excel
  - 具备财务知识，理解指标定义
  - 进行基础财务计算与比率分析
  - 以可视化或模型形式输出
- **优先级**: ⭐⭐⭐ 中高

## 安全与合规需求

| 需求项 | 具体要求 |
|--------|----------|
| 数据训练 | 上传数据不用于模型训练 |
| 行业标准 | 支持ISO等行业合规标准 |
| 数据隐私 | 任务内容默认私密 |
| 分享机制 | 需用户主动分享才可查看 |
| 企业管理 | 企业用户可查看团队任务记录 |
| 合规审计 | 任务记录不可删除，满足监管需求 |

# 任务规划：场景专有 Prompt 优化

## 🎯 目标
优化 `ai_designer.py` 的场景适配能力，通过高密度信息压缩词实现不同演讲场景的专有 Prompt，提升内容呈现与场景的匹配度。

## 📊 当前状态分析

### 已有场景类型 (design_system.py)
| 场景 | 英文标识 | 当前支持 |
|------|----------|----------|
| 咨询研究/汇报 | consulting | ✅ 颜色 |
| 年终述职/总结 | annual_review | ✅ 颜色 |
| 公司/项目介绍 | company_intro | ✅ 颜色 |
| 学术研究/答辩 | academic | ✅ 颜色 |
| 创意/营销 | creative | ✅ 颜色 |
| 政府公文 | government | ✅ 颜色 |

### 当前问题
1. **大纲生成** (`_build_outline_prompt`): 无场景差异化
2. **内容页生成** (`_build_content_prompt`): 无场景差异化
3. **演讲稿生成** (`generate_speech_script`): 仅简单关键词匹配
4. **System Prompt**: 通用设计师角色，无场景人格

## 📐 Phase 1: 设计场景 Prompt 矩阵 [complete]
**目标**: 为每个场景定义高密度压缩指令

### 1.1 场景维度分析
- **内容结构**: 金字塔 vs 时间线 vs 问题导向
- **语言风格**: 正式/学术 vs 商务 vs 创意
- **数据偏好**: 图表密集 vs 案例驱动 vs 概念可视化
- **视觉调性**: 严肃稳重 vs 现代简约 vs 活力创新

### 1.2 高密度压缩词设计
每个场景用 3-5 个压缩词概括：
- `[TONE]`: 语调
- `[STRUCTURE]`: 结构模式
- `[VISUAL]`: 视觉偏好
- `[DATA]`: 数据呈现
- `[AUDIENCE]`: 受众预期

# 公告邮件模板

用户群发邮件的 HTML 模板，采用瑞士杂志风格设计。

## 文件列表

| 文件 | 日期 | 用途 |
|------|------|------|
| `内部试用通知.html` | 2024-12 | 内测邀请函 |
| `版本更新公告_2025年1月.html` | 2025-01 | v2.0 版本更新公告 |

## 设计规范

- **字体**: Noto Sans SC + Noto Serif SC
- **主色**: #0F172A (深蓝灰) + #2563EB (蓝)
- **风格**: 瑞士极简、高对比、专业严谨
- **布局**: 单栏卡片式，最大宽度 520px

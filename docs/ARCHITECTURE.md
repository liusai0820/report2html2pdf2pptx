## 核心模块

### 1. CLI (cli.py)
- 命令行界面
- 用户交互
- 参数解析
- 进度显示

### 2. SlideGenerator (slide_generator.py)
- 核心生成逻辑
- 流程编排
- 并发控制
- 错误处理

### 3. AIClient (ai_client.py)
- AI API 封装
- 提示词管理
- 重试机制
- 响应解析

### 4. DocumentParser (document_parser.py)
- 多格式文档解析
- 内容提取
- 结构化处理

### 5. TemplateMerger (template_merger.py)
- HTML 模板管理
- 内容注入
- 页面合并

### 6. PDFGenerator (pdf_generator.py)
- HTML 转 PDF
- 页面渲染
- 文件合并

### 7. AdobeIntegration (adobe_integration.py)
- PDF 转 PPTX
- Adobe API 调用
- 批量处理

## 数据流

```
输入文档 (JSON/MD/DOCX)
    ↓
DocumentParser 解析
    ↓
SlideGenerator 生成大纲
    ↓
AIClient 生成内容 (并发)
    ↓
TemplateMerger 合并模板
    ↓
HTML 文件
    ↓
PDFGenerator 转换
    ↓
PDF 文件
    ↓
AdobeIntegration 转换
    ↓
PPTX 文件
```

## 配置管理

所有配置集中在 `config.py` 中：

- API 密钥和端点
- 生成参数（并发数、超时、重试）
- 路径配置
- 模型选择

环境变量通过 `config/.env` 加载。

## 错误处理

1. **重试机制**: API 调用失败自动重试
2. **超时控制**: 防止长时间阻塞
3. **优雅降级**: 部分失败不影响整体
4. **详细日志**: Rich 库提供美观的进度和错误信息

## 性能优化

1. **并发生成**: 使用 asyncio 并发生成多个页面
2. **信号量控制**: 限制并发数避免过载
3. **智能上下文**: 只注入相关内容，减少 token 消耗
4. **缓存机制**: 模板和配置缓存复用

## 扩展性

- **插件化设计**: 易于添加新的文档格式解析器
- **模板系统**: 支持自定义 HTML 模板
- **API 抽象**: 易于切换不同的 AI 服务
- **配置驱动**: 通过配置文件调整行为

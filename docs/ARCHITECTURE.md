# SlideCraft AI - 系统架构图

> 最后更新: 2026-01-06

## 🎯 概述

SlideCraft AI 是一个基于大语言模型的演示文稿自动生成系统。用户上传文档后，系统会自动解析内容、规划大纲、设计页面、生成 PDF/PPTX。

---

## 📁 关键文件清单

| 层级 | 文件 | 职责 |
|-----|------|-----|
| **前端** | `frontend/src/App.jsx` | React 主组件，SSE 监听，预览渲染 |
| **API** | `src/server.py` | FastAPI 主入口，路由定义 |
| **适配** | `src/v2_adapter.py` | V2 引擎与 API 的桥梁，SSE 流编排 |
| **核心** | `src/v2/ai_designer.py` | AI 设计师，Prompt 构建，大纲/页面生成 |
| **设计** | `src/v2/design_system.py` | 设计系统，配色方案，字体配置 |
| **样式** | `src/v2/unified_styles.py` | 统一 CSS 生成 |
| **验证** | `src/v2/validator.py` | HTML 验证与修复 |
| **渲染** | `src/core/output_renderer.py` | 页面合并，PDF/PPTX 生成 |
| **存储** | `src/r2_storage.py` | Cloudflare R2 上传 |
| **图片** | `src/v2/image_generator.py` | ComfyUI/Unsplash 背景图 |

## 📊 SSE 事件流

| 事件 | 进度 | 说明 |
|------|------|-----|
| `context` | 5% | 正在解析文档 |
| `outline` | 10-20% | AI 规划大纲 |
| `content` | 25-85% | 并行生成页面 |
| `preview_ready` | 90% | 预览就绪，可开始浏览 |
| `pdf` | 92-98% | PDF 生成中 |
| `pptx` | 99% | PPTX 转换中 |
| `done` | 100% | 全部完成 |

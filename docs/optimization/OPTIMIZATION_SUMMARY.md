## 优化内容

### 1. 演讲稿生成 Prompt 优化 ✅

**文件**：`src/v2/ai_designer.py`
**函数**：`generate_speech_script` (行 1022-1252)

**主要改进**：

#### 1.1 智能时长控制（1043-1052 行）
- 短汇报（<10分钟）：精简模式，80-120字/页
- 中等汇报（10-20分钟）：适中模式，100-150字/页
- 长汇报（>20分钟）：详细模式，120-200字/页

#### 1.2 场景类型适配（1054-1081 行）
- **工作汇报/报告**：成果导向、数据为主、问题与对策
- **项目答辩/评审**：可行性论证、技术细节、预判质疑
- **述职报告**：个人贡献、成长思考、问题反思
- **一般性汇报**：专业客观、逻辑清晰

#### 1.3 Prompt 内容增强
- **段落结构**：引导注意 → 核心论点 → 数据支撑 → 承上启下
- **过渡语句**：4 大类（章节/内容/强调/引导），10+ 示例
- **数据解读**：4 类数据话术（增长趋势/对比分析/占比说明/图表解读）
- **互动技巧**：新增专门模块（引导注意力/强调重点/节奏把控）
- **禁忌清单**：新增 2 条（不要只报数据不解读/不要过渡语单调重复）

### 2. 演讲稿模态框组件优化 ✅

**文件**：`frontend/src/components/ResultView.jsx`
**组件**：`SpeechScriptModal` (行 19-394)

**设计风格**：编辑杂志/文档阅读器

**主要功能**：

#### 2.1 三套精致主题
- **日间模式**：纯白背景，深灰文字，蓝色强调
- **护眼模式**：暖米黄背景，深棕文字，棕色强调
- **夜间模式**：深灰黑背景，浅灰文字，浅蓝强调

#### 2.2 阅读辅助
- **字号调节**：S (14px) / M (16px) / L (18px) / XL (20px)
- **一键复制**：复制全文，带成功反馈
- **下载文稿**：保存为 Markdown 文件

#### 2.3 排版优化
- **字体系统**：
  - 标题：Inter / PingFang SC（无衬线）
  - 正文：Newsreader / Source Serif Pro / Noto Serif SC / Georgia（衬线）
- **间距**：动态行高（1.75-1.8），两端对齐
- **视觉细节**：自定义滚动条、淡入动画、渐变分隔线

#### 2.4 增强的 Markdown 渲染
- 支持 H1/H2/H3、粗体/斜体、列表
- 演讲专用标记：`[过渡]`、`[停顿]`
- 分隔线：`---` 渲染为渐变线

#### 2.5 精致的加载与错误状态
- 加载：旋转环绕麦克风图标 + 脉冲点动画
- 错误：清晰的错误提示界面

# /src/prompts - Prompt 工程系统

> ⚠️ **一旦我所属的文件夹有所变化，请更新我。**

## 架构 (3 行)

```
Prompt工程的大脑 ── 管理场景模板、Prompt生成、质量检查
       │
       └── 根据不同使用场景动态构建最优Prompt，确保AI输出质量
```

## 文件清单

| 文件                  | 地位     | 功能                                              |
| --------------------- | -------- | ------------------------------------------------- |
| `prompt_engine.py`    | **核心** | Prompt 引擎，动态构建完整的 AI 提示词             |
| `scenario_prompts.py` | **核心** | 场景模板库，定义咨询/政务/学术等场景的专属 Prompt |
| `methodology.py`      | 方法论   | 幻灯片设计方法论，指导 AI 的排版与内容策略        |
| `quality_checker.py`  | 质检     | 输出质量检查，验证 AI 生成内容的规范性            |
| `__init__.py`         | 模块     | 包初始化与公共导出                                |

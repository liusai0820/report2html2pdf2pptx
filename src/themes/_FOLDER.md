# /src/themes - 主题系统

> ⚠️ **一旦我所属的文件夹有所变化，请更新我。**

## 架构 (3 行)

```
视觉主题的调色板 ── 管理颜色方案、CSS生成、主题预览
       │
       └── 让每套幻灯片都有独特的视觉风格，同时保持设计一致性
```

## 文件清单

| 文件                  | 地位     | 功能                                           |
| --------------------- | -------- | ---------------------------------------------- |
| `theme_registry.py`   | **核心** | 主题注册表，定义所有可用主题及其配色方案       |
| `theme_manager.py`    | **核心** | 主题管理器，处理主题选择、切换、应用           |
| `css_generator.py`    | 生成     | CSS 生成器，根据主题配置动态生成样式表         |
| `prompt_generator.py` | Prompt   | 主题感知的 Prompt 生成，让 AI 理解当前视觉风格 |
| `preview.py`          | 预览     | 主题预览逻辑，生成主题效果示例                 |
| `__init__.py`         | 模块     | 包初始化与公共导出                             |

## 主题配色结构

```python
Theme = {
    "name": "主题名称",
    "colors": {
        "primary": "#xxx",      # 主色
        "secondary": "#xxx",    # 辅色
        "background": "#xxx",   # 背景
        "text": "#xxx",         # 正文
        "accent": "#xxx"        # 强调色
    },
    "fonts": {...},
    "spacing": {...}
}
```

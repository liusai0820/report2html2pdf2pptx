## 架构 (3 行)

```
AI编排与上下文管理中枢 ── 协调文档解析、AI调用、输出渲染
        │
        └── 构建完整的生成上下文，驱动整个幻灯片生成流水线
```

## 文件清单

| 文件                 | 地位     | 功能                                      |
| -------------------- | -------- | ----------------------------------------- |
| `ai_orchestrator.py` | **核心** | AI 编排器，协调多轮 AI 对话，管理生成策略 |
| `context_builder.py` | **核心** | 上下文构建器，从文档提取并结构化关键信息  |
| `generator.py`       | 生成     | 统一生成器入口，封装 V1/V2 引擎选择逻辑   |
| `output_renderer.py` | 渲染     | 输出渲染器，将生成结果转换为最终 HTML     |
| `__init__.py`        | 模块     | 包初始化与公共导出                        |

## 核心流程

```
文档 ──▶ context_builder.py ──▶ ai_orchestrator.py ──▶ generator.py
                │                       │                   │
                ▼                       ▼                   ▼
          结构化上下文           AI多轮对话            V2引擎调用
                                        │                   │
                                        ▼                   ▼
                                output_renderer.py ◀────────┘
                                        │
                                        ▼
                                   HTML 幻灯片
```

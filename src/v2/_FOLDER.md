# /src/v2 - 下一代引擎

> **⚠️ 一旦本文件夹有所变化，请更新我。**

V2 引擎：AI 原生设计系统。包含图像生成、设计师逻辑、统一样式、原子化 Prompt 系统。

---

## 子目录

| 目录       | 功能                                       |
| ---------- | ------------------------------------------ |
| `prompts/` | 原子化 Prompt 系统（场景 Prompt、演讲稿等）|

## 文件列表

| 文件                 | 地位     | 功能                                             |
| -------------------- | -------- | ------------------------------------------------ |
| `image_generator.py` | **核心** | 图像生成调度器，支持 ComfyUI/OpenRouter/Unsplash |
| `ai_designer.py`     | 设计师   | AI Prompt 工程，决定页面布局和内容               |
| `unified_styles.py`  | 样式系统 | 统一的 CSS 变量和组件样式                        |
| `engine.py`          | 生成引擎 | 协调各组件，执行完整生成流程                     |
| `page_templates.py`  | 模板     | 各类页面的 HTML 模板                             |
| `design_system.py`   | 设计系统 | 设计 Token 和场景配置                            |
| `validator.py`       | 验证器   | HTML 输出验证                                    |

# /src - 后端核心

> **⚠️ 一旦本文件夹有所变化，请更新我。**

Python 后端引擎。处理 API 请求、AI 编排、文档解析、输出渲染。

---

## 子目录

| 目录       | 地位        | 功能                                |
| ---------- | ----------- | ----------------------------------- |
| `core/`    | 核心引擎    | AI 编排器、上下文构建器、输出渲染器 |
| `v2/`      | 下一代引擎  | 图像生成、设计师逻辑、统一样式      |
| `themes/`  | 主题系统    | CSS 生成器、主题管理器              |
| `prompts/` | Prompt 工程 | 各场景的提示词模板                  |

## 文件列表

| 文件                 | 地位     | 功能                                 |
| -------------------- | -------- | ------------------------------------ |
| `server.py`          | **入口** | FastAPI 主服务，所有 HTTP 请求的网关 |
| `config.py`          | 配置中心 | 加载环境变量，提供全局配置           |
| `mailer.py`          | 邮件服务 | SMTP 发信、Gmail 草稿保存            |
| `db.py`              | 数据库   | Supabase 交互（用户配额管理）        |
| `comfyui.py`         | 图像生成 | 与本地 ComfyUI 通信                  |
| `v2_adapter.py`      | 适配器   | 连接 v1 API 与 v2 引擎               |
| `document_parser.py` | 文档解析 | 支持 PDF/DOCX/MD/TXT                 |
| `workflow_api.json`  | 资源     | ComfyUI 工作流模板                   |

# /frontend/src - 前端源码

> ⚠️ **一旦我所属的文件夹有所变化，请更新我。**

## 架构 (3 行)

```
React应用源码 ── 组件、API、状态管理、样式
       │
       └── App.jsx为主入口，components/为UI组件，api.js为后端通信
```

## 文件清单

| 文件        | 地位       | 功能                                     |
| ----------- | ---------- | ---------------------------------------- |
| `App.jsx`   | **主入口** | 应用主组件，包含路由、状态管理、页面布局 |
| `Admin.jsx` | 管理后台   | 后台管理页面，用户管理、数据趋势、套餐管理 |
| `main.jsx`  | 入口       | React 渲染入口点                         |
| `api.js`    | 通信       | 后端 API 调用封装，SSE 流处理            |
| `index.css` | 样式       | 全局 CSS 样式                            |

## 子目录

| 目录          | 地位        | 职责                                                     |
| ------------- | ----------- | -------------------------------------------------------- |
| `components/` | **UI 组件** | 所有 React 组件 (UploadZone, ConfigPanel, ResultView 等) |
| `contexts/`   | 状态        | React Context 状态管理                                   |
| `lib/`        | 工具        | 工具库 (Supabase 客户端等)                               |
| `assets/`     | 资源        | 图片、图标等静态资源                                     |
